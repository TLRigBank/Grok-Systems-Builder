# Artifact Standards

## Minimum Bar for Any Module Artifact

Every submitted artifact must:

- Actually run or be demonstrably complete
- Directly demonstrate the module’s core skill
- Include enough documentation for another practitioner to understand and (where applicable) run it
- Be honest about limitations and open questions

Artifacts that are purely descriptive, incomplete, or disconnected from the module objectives will be returned for revision.

## Final Portfolio Expectations

The portfolio is the primary credibility mechanism of the path. It should:

- Contain a coherent body of work rather than disconnected exercises
- Show progression from earlier modules into a more integrated system or set of systems
- Include clear narrative of design choices and trade-offs
- Provide evaluation or reliability evidence where relevant
- Be suitable for public gallery listing if the learner opts in

## Review Outcomes

- **Approved** → Grok Systems Builder – Verified credential + optional public gallery
- **Needs Revision** → Specific feedback; learner may resubmit
- **Not Ready** → Clear gaps identified; further module work recommended

Rubrics are public. Review is never a black box.
