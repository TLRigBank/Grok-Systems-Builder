# Core Design Principles

1. **Artifact over attendance**  
   Progress is demonstrated by work, not by time spent or modules opened.

2. **Public proof**  
   The lasting credential is a reviewed, preferably public, runnable portfolio.

3. **Human judgment with transparent rubrics**  
   Review is performed by humans (or rigorously rubric-driven processes) against published criteria.

4. **Practitioner density**  
   Content and requirements are written for people who already ship software or systems. No beginner padding.

5. **Independence**  
   This path does not claim official xAI endorsement. Its credibility comes from the quality of the work it produces.

6. **Compounding capability**  
   Each module builds on the previous. The final portfolio should feel like a coherent body of work, not a collection of disconnected exercises.
