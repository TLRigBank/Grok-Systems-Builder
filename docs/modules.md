# Module Overview (Living Draft)

This is a high-level map. Individual lesson content and exact artifact specifications will be refined over time.

## Module 0 — Orientation & Mindset
- What “systems thinking with Grok” actually means
- How this path differs from courseware and certifications
- Setting up a durable working environment
- **Artifact:** Personal systems learning charter + initial workspace setup

## Module 1 — Foundations of Reliable Grok Systems
- Prompt architecture for production use
- Context management and long-horizon coherence
- Evaluation basics
- **Artifact:** A small but complete, evaluated tool-using agent

## Module 2 — Tools, MCP, Skills & Grounding
- Designing clean tool interfaces
- Real-time grounding patterns
- Error handling and graceful degradation
- **Artifact:** A grounded multi-tool system with clear failure modes documented

## Module 3 — Multi-Agent Orchestration
- Specialist roles and handoffs
- Debate, critique, and synthesis patterns
- State and memory across agents
- **Artifact:** A coordinated multi-agent workflow that produces a non-trivial deliverable

## Module 4 — Production Patterns
- Reliability, observability, and cost awareness
- Evaluation harnesses
- Human-in-the-loop design
- **Artifact:** Production-ready patterns applied to a previous artifact (hardened version)

## Module 5 — Architectural Judgment
- Trade-off analysis under real constraints
- When *not* to use multi-agent systems
- Scaling and maintenance considerations
- **Artifact:** Architecture decision records + reasoned alternative designs

## Module 6 — Portfolio Capstone
- Integration of prior work into a coherent, runnable system
- Documentation and demonstration
- Submission for review
- **Artifact:** Final portfolio package (code + narrative + evaluation evidence)

---

Modules may be reordered or refined. The constant requirement is that each stage produces evidence of capability.
