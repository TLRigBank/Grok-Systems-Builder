# Grok Systems Builder – Wireframes

Extracted from the original product specification document (`Grok Systems Builder.docx`).

These are the UI wireframes for the desktop web interface, ordered by the primary user flows.

| File | Screen | Primary Users |
|------|--------|---------------|
| `01-landing-page.png` | Landing Page | Visitors |
| `02-signup-login.png` | Sign Up / Login | Visitors → Learners |
| `03-public-portfolio-gallery.png` | Public Portfolio Gallery | Visitors, Learners |
| `04-dashboard.png` | Dashboard | Learners |
| `05-learning-path.png` | Learning Path (Modules Overview) | Learners |
| `06-lesson-view.png` | Lesson View | Learners |
| `07-module-checkpoint.png` | Module Checkpoint (Artifact + Feedback) | Learners |
| `08-portfolio-submission.png` | Portfolio Submission | Learners (Verified track) |
| `09-completion-certificate.png` | Completion / Certificate | Verified Learners |
| `10-account-settings.png` | Account Settings | Learners |
| `11-admin-dashboard.png` | Admin Dashboard / Analytics | Admins |
| `12-admin-user-detail.png` | Admin – User Detail View | Admins |
| `13-admin-review-queue.png` | Admin – Portfolio Review Queue | Admins |

These wireframes, together with `docs/user-stories.md` and the curriculum docs, form the complete brief for implementing the interface (suitable for feeding into Grok Build or any frontend agent).

**Note:** The PNG wireframe files are large (~25 MB total). They have been extracted and are available for download from the conversation artifacts or can be uploaded directly to this folder via the GitHub web interface.
