# Grok Systems Builder

**A practical, evidence-based learning path that turns practitioners into people who can design, build, and reason about production-grade systems with Grok and Grok Build.**

We reject certificate-only learning. Every module requires a real artifact. The final gate is a reviewed, runnable portfolio. The public gallery of approved work is the lasting proof of competence.

## Positioning

An independent, high-signal practitioner path for people who want to ship real multi-agent and tool-using systems with Grok — not just complete modules.

**Credential:** Learners who complete all modules and pass portfolio review earn the **Grok Systems Builder – Verified** credential. This signals that a human reviewer (using public rubrics) has examined their work. It does not claim official xAI endorsement.

## Core Promise

You will leave with more than knowledge. You will leave with a public, runnable body of work that demonstrates architectural judgment under real constraints.

## Who This Is For

**Primary**
- Developers, solution architects, AI engineers, and technical leads with intermediate experience
- People seeking structured mastery of Grok Build, multi-agent orchestration, tools/MCP/skills, real-time grounding, and production reliability

**Secondary**
- Teams evaluating Grok for production use who need internal upskilling
- Independent builders who want a credible public portfolio of Grok systems

**Not primary:** Absolute beginners or pure prompt engineers seeking a quick badge.

## Path Structure

| Module | Focus | Required Artifact |
|--------|-------|-------------------|
| 0 | Foundations & Setup | Working setup + notes |
| 1 | Grok Build Fluency & Configuration | Configured project + design decisions |
| 2 | Tools, Skills, Plugins & MCP | Working tool/MCP agent + docs |
| 3 | Multi-Agent Orchestration | Runnable multi-agent system |
| 4 | Reliability, Grounding & Evaluation | Hardened system + evaluation notes |
| 5 | Integration, Scenarios & Capstone Prep | Scenario responses + ADRs |
| 6 | Portfolio Capstone | Final reviewed portfolio package |

See [docs/modules.md](docs/modules.md) for full learning objectives.

## Design Principles

- Artifact over attendance
- Public proof over private certificates
- Rubric-based human review
- Sequential unlocking with evidence gates
- Practitioner-to-practitioner density
